# Dominó SEOSP — Placar Oficial

Placar ao vivo do Dominó SEOSP (Lei Municipal nº 0608/2026), para usar no celular.

- **Site:** https://jnnvld.github.io/domino-seosp/
- **Dados:** Firebase Firestore (projeto `domino-seosp`, plano Spark gratuito).
- **Quem registra:** qualquer pessoa com o link.
- **Quem altera o site:** só quem tem acesso a este repositório.

## Arquivos
- `index.html` — o app inteiro.
- `dados-iniciais.json` — mesas e jogadores do placar antigo (importados pelo Modo presidente).
- `firestore.rules` — regras de segurança do banco (cópia do que está publicado no console do Firebase).
